    # Object-Oriented Programming (OOP)

## What is OOP?
Object-Oriented Programming (OOP) is a programming paradigm that organizes software around objects rather than functions or procedures. An object combines data (attributes) and behavior (methods) into a single unit.

In simple words, OOP models real-world entities such as a Car, Student, Bank Account, or Employee as software objects.

## Definition
Object-Oriented Programming (OOP) is a programming paradigm in which software is designed using objects that contain both data (state) and methods (behavior). It improves code organization, reusability, maintainability, and scalability.

## Why was OOP introduced?
Before OOP, programmers mainly used Procedural Programming, where programs were written as a sequence of functions.

Example:
login()
logout()
payment()
order()

As software became larger, procedural programming had several limitations:
- Code duplication
- Difficult maintenance
- Poor scalability
- Weak data security
- Hard to reuse code

OOP was introduced to solve these problems by organizing programs into objects.

## Real-World Analogy

Car

Properties (Data)
- Brand
- Color
- Speed
- Fuel
- Model

Behaviors (Methods)
- start()
- stop()
- accelerate()
- brake()

A car is not only its properties but also its actions. Similarly, an object in programming contains both data and methods.

## Why do we use OOP?
- Organize code into logical units.
- Reuse existing code.
- Reduce duplication.
- Protect important data.
- Easily maintain software.
- Easily add new features.
- Model real-world entities naturally.

## OOP vs Procedural Programming

Procedural Programming
- Focuses on functions.
- Data and functions are separate.
- Less secure.
- Difficult to maintain.
- Less reusable.
- Suitable for small projects.

Object-Oriented Programming
- Focuses on objects.
- Data and functions are grouped together.
- More secure.
- Easy to maintain.
- Highly reusable.
- Suitable for large projects.

## Advantages of OOP
1. Code Reusability
2. Easy Maintenance
3. Better Security
4. Scalability
5. Real-World Modeling

## Disadvantages of OOP
- Requires more memory.
- Slightly slower due to object creation.
- Can be complex for beginners.
- Not ideal for very small programs.
